# Mostar City — Cinematic Scroll

A standalone cinematic scroll story for Mostar city, built with vanilla HTML/CSS/JS.

## Run locally

Open `index.html` in any modern browser. No build step required.

## Publish on GitHub Pages

1. Create a new repository on GitHub (e.g. `mostar-city`).
2. Push this folder to the repository.
3. In the repo settings, enable **GitHub Pages** from the `main` branch (root).
4. Your site will be live at `https://<username>.github.io/mostar-city/`.

## Files

- `index.html` — markup
- `styles.css` — styles
- `script.js` — animation engine
